# Documentation index

Documentation and supporting validation artifacts are grouped by game. The
[source asset-format atlas](source-asset-formats.md) inventories the supplied
FF1, FF1 Xbox, FF2, FF2 Xbox, FF2 Wii and FF3 asset trees and links the
game-scoped format references.

| Area | Contents |
|---|---|
| [FF1](ff1/guide.md) | PS2 format inventory, lighting and color/pose guides, validation evidence |
| [FF1 Xbox](ff1x/guide.md) | Xbox format inventory, reports and PKX, MPX/0x1060 and XPR0 references |
| [FF2](ff2/mdl-format.md) | PS2 format inventory, model and texture notes, validation artifacts |
| [FF2 Xbox](ff2x/README.md) | MDL, PK2, PPD, XPR0 and ancillary-file references; parser limits |
| [FF2 Wii](ff2w/guide.md) | Wii format inventory, ANMB animation, repair notes and MDLB, PK2B, PPDB formats |
| [FF3](ff3/formats.md) | PS2 format inventory, nested PK4/SGD models, TIM2 pictures and auxiliary observations |
| [Architecture](architecture/gltf-export-pipeline.md) | Shared export pipeline |
| [History](history/delivery-manifest.json) | Historical delivery manifests |

Each game's `validation/` folder contains the inspection data and work reports
associated with its documentation.
