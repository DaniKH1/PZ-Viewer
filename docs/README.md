# Documentation index

Documentation and supporting validation artifacts are grouped by game.

| Area | Contents |
|---|---|
| [FF1](ff1/guide.md) | PS2 guides, lighting and color/pose notes, validation evidence |
| [FF1 Xbox](ff1x/guide.md) | Guides, reports and PKX, SGD 0x1060 and XPR0 formats |
| [FF2](ff2/mdl-format.md) | PS2 model and texture notes, validation artifacts |
| [FF2 Wii](ff2w/guide.md) | Wii guides, ANMB animation, repair notes and MDLB, PK2B, PPDB formats |
| [Architecture](architecture/gltf-export-pipeline.md) | Shared export pipeline |
| [History](history/delivery-manifest.json) | Historical delivery manifests |

Each game's `validation/` folder contains the inspection data and work reports
associated with its documentation.
